## [Recall](./recall) — adaptive spaced-repetition study planner

A full-stack app that helps students remember what they learn. It schedules reviews at the right time, quizzes them
with active recall, and adapts each schedule to how well they remember. Built with React, Express, TypeScript and SQLite.
See [`recall/README.md`](./recall/README.md) to run it.
